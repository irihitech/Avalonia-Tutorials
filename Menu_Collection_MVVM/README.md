# Menu Collection MVVM

This tutorial demonstrates how to use Avalonia's `Menu` control with the MVVM pattern.

## Features

- Binding `Menu.ItemsSource` to a collection of `MenuItemViewModel`
- Using `Menu.ItemContainerTheme` to bind `Header`, `ItemsSource`, and `Command` on each `MenuItem`
- Nested sub-menus driven by MVVM

## Requirements

- Avalonia 11.3.12
- Semi.Avalonia 11.3.7.3
- CommunityToolkit.Mvvm 8.2.2
