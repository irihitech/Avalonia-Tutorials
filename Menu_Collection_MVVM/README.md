# Menu Collection MVVM

This tutorial demonstrates how to use Avalonia's `Menu` control with the MVVM pattern.

本教程演示如何在 MVVM 模式下使用 Avalonia 的 `Menu` 控件。

## Features

- Binding `Menu.ItemsSource` to a collection of `MenuItemViewModel`
- Use a `Style` to specify how to bind `MenuItem` properties to `MenuItemViewModel` properties

## 功能特性

- 将 `Menu.ItemsSource` 绑定到 `MenuItemViewModel` 集合
- 使用 `Style` 指定如何将 `MenuItem` 属性绑定到 `MenuItemViewModel` 属性

## Notice

- You may encounter an type casting exception. Please ignore it and continue debugging. This is expected in debug mode and does not affect the functionality of the application. It works well in release applications.

## 注意事项

- 您可能会遇到类型转换异常。请忽略它并继续调试。这在调试模式下是正常的，不会影响应用程序的功能。在发布版本中可以正常工作。
